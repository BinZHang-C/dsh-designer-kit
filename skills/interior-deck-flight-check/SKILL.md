# 室内概念册 · 出册审计

蒸馏自 Analyst Academy flight-check + deck-review-rubric，裁到室内汇报。

## 原则
- 每条 finding 必须可定位：交付版本 + 页码 + 最终页面上的标题或原句摘录；源 MD/讲稿只供追溯，不能代替实际页面。
- 审**模式**不机械扫词：「驱动价值」在无对象时才打；「层高驱动视线」可留。
- 严重级：🔴 会上翻车 > 🟡 削弱说服 > ⚪ 口味（标清可弃）。

## 检查项

### 1. 标题与已确认叙事（内容页）
先读项目已确认的受众、标题视角与页型口径，再只扫标题判断叙事是否连贯。使用者体验、旅程标题或短标签符合该口径时不判错；尚无口径时，建议叙事页用能承担内容的主张句，不因一种句式偏好发起全册改写。

### 2. 证据与来源（三层）
- L1 能否定位依据（任务书文件/页码、现场记录、可指认案例）；外部链接可选，不作为交付门槛
- L2 来源是否像真的（具体项目/条款，不是「行业研究」）
- L3 能核才核；不能核则标明「未核验」  
无依据的量化（面积、造价、人流）= 🔴 或明确标为待核假设。非量化页面可用图像、场景或空间关系作为证据，不要求每页补数字。

### 3. AI 腔模式（多信号合取，单点不判死刑）
三联形容词、无对象空动词、套话开场、反复「不是A而是B」、每页破折号连接器、完美三件套。

### 4. 诚实
裁切轴、选择性对比、把概念效果图写成实景、墙面他司字未遮 = 🔴。

### 5. 收尾只给两刀
报告末尾只写：**最重要的两个修复**（有页码），避免四十条并列。

## 输出
```
出册审计 · [册名]
🔴 …
🟡 …
⚪ …
两刀: (1) … (2) …
放行: 是/否
```

## 硬禁
- 不把字体口味和缺主张标成同级
- 不在验收体裁上强行套概念 claim 审计
