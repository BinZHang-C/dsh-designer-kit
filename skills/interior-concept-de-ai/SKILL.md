# 室内概念册 · 去AI味

蒸馏自 humanize-presentations + 中文 humanize 禁项，裁切到室内概念汇报。

## 何时用
- 已有册/大纲文案要收紧
- 出册前、接触片牵涉文案可信度
- 「像 Gamma / 像咨询腔 / 标题是标签」

## Rubric 保护（有证据才保护，勿报勿拆）
1. 章节 / page_type 序列（产品或大纲已锁）
2. 节名、扉页短标、模板规定的页题角色名
3. 并行空间循环（各 SPACE 重复同一页型组）

模板 chrome（眉脚、母题、页码）默认不动。项目已确认的受众、标题视角与页型口径优先；使用者体验、旅程标题或短标签不因润色被改回设计师判断句。

## Tier 1（可直接改字，不删行不删页）
- 空词：赋能/全面/无缝/生态/闭环/抓手 → 删或换成可核对的具体词（做法、尺寸、客群动作）
- 套话开场收尾：在当今、值得注意的是、综上所述、此外、不可否认 → 删，留主张
- 「不是 A 而是 B」→ 直接说 B
- 破折号堆、名词堆 → 口语动词（贴地：压动线、降层高噪音、把接待压到 N 步）
- 同页同义词轮转（空间/场所/场域）→ 统一一个词

## Tier 2（菜单，等用户点头；少闸默认不做）
1. **字数检查**（中文按字）：按最终页面可见的标题与正文计数，不计讲稿或源 MD 中未上页的文字。项目已确认预算优先；未定预算时 >80 提醒、>120 建议拆页/附录，结合图面与阅读距离判断，封面·纯大图·材料板可单列。
2. **同页 section 标签 ≤1**：标题带与页脚勿重复同一节名。
3. **标题服务叙事**：先核对项目已确认视角；未定口径时，叙事/概念/结论页优先用有内容的主张句。COVER/TOC/扉页/平面/材料板/附录可用短标签。
4. 演讲旁白落页（如何读此图）→ 并入内容或进备注。
5. 三件套凑数、bullet 墙、无证据空框架 → 合并/补证据/删页。

## 室内特有禁改
- 不把材料板/平面/封面/验收页强改成咨询 claim
- 不把「木饰面 / 石材」工艺说明改成空洞愿景句

## 输出
```
去AI味 · [册名/页范围] · 模式
字数: 均__/最大__ · >80:n · >120:n
Rubric保护: …
Tier1: …
Tier2菜单: （深出才列）
```
