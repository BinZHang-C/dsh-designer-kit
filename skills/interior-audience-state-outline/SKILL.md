# 室内概念册 · 观众状态大纲

蒸馏自 LevenAn/humanize-ppt（AST：观众状态改变器），裁到室内汇报。

## 核心判断
PPT 不是信息容器，是**改变甲方认知状态**的装置。  
AI 直出最易把「解释欲、推理痕迹、总结腔」写进页面——本 skill 先洗净再交给主张大纲/生成器。

## 先填五格（未填完不出页）
1. **观众是谁**：业主 / 招标委员会 / 内部投委会 / 使用部门（可多选，标主受众）
2. **看之前相信什么**：例如「大厅越大越有面子」「先效果图再谈平面」
3. **看完后应相信什么**：一句可复述的走廊句
4. **最大认知张力**：现状矛盾或利益冲突（一句话）
5. **页序列如何推状态**：每页只推进一步，不堆资料

## 再交下游
- 五格 → 主张大纲（claim + evidence）
- 禁止在本步写长正文或贴思维链
- 标下游：生成器 / 审美基线 / 渲前保全

## 输出
```
观众状态大纲 · [项目]
受众: …
之前: …
之后（走廊句）: …
张力: …
页推进（短标或主张草稿）:
1. …
Skim走廊句: 能否被复述？是/否
下游: 主张大纲 → …
```

## 硬禁
- 不把推理过程写进页正文
- 不跳过张力直接堆效果图清单
