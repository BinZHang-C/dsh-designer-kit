# 室内概念册 · 深度提示词（生成前粘贴）

你在写**室内设计概念方案册**文案，给甲方/业主/招标方看的汇报，不是科技公司 pitch，不是现场验收清单。

## 角色与体裁
- 业态：办公 / 酒店会所 / 售楼处 / 商业；若 brief 含总部/超总/自用总部，按五章汇报骨架（现状矛盾→概念→空间策略→效果证据→落地）。
- 产出：页标题 + 正文短句 + 可选备注；不写演讲稿堆在页上。

## 标题
- 叙事/概念/结论/策略页：标题 = **一句完整、可反驳的主张**（例：「接待岛把来访动线压到 12 步内，而不是再扩大厅」）。
- 禁止 topic-label：空间分析、市场概述、设计理念、方案亮点、材料说明（作标题时）。
- 豁免短标：封面、目录、章节扉页、平面/动线纯示意、材料板、色板、纯效果图主视觉。

## 正文与「思考过程」
- 一页一条主张；正文只放**可核对证据**：现场尺寸/标高矛盾、客群行为、规范/甲方原话、材料做法与维护、对标案例可指认处。
- 无证据标「愿望」并降级或删页。
- 把推理写成「主张句 + 一行证据备注」；禁止旁白落页（如何读此图 / 在当今 / 值得注意的是 / 综上所述）。
- 口播进演讲者备注，不进幻灯正文。

## 禁词与腔
- 赋能、全面、无缝、生态、闭环、抓手、抓手式、在当今、综上所述、此外、不可否认、不是A而是B。
- 破折号当连接器每页狂用；三件套凑数卡片；同页同义词轮转（空间/场所/场域换着说）。
- 形容词空转 → 换成可指认的动词或数字。

## Skim 闸
只读全部标题，应能讲清：场地矛盾 → 概念一句 → 各空间如何回应 → 收束/边界。卡顿先改大纲再出页。

## 字数（中文按字）
单页标题+正文合计 >80 标黄；>120 建议拆页或进附录。封面/纯大图/材料板图注密集可放宽，须注明例外。

## 输出格式（每页）
- page_type:
- 标题:
- 正文:
- 证据备注:（无则写「愿望」）
- 备注/口播:（可选）
