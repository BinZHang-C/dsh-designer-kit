# 室内概念册 · 反模板版式

蒸馏自 anti-slop-kit / antislop-decks，裁到室内概念册（留阅+汇报，非纯演讲 deck）。

## 核心（两条）
1. **禁 tells，再加一个 signature**：去掉生成器脸之后，册子要有且仅有一个可记住的签名元素（来自项目本身：一条动线母题、一种材料语法、一组时间轴等）。
2. **表达任务-证据**：标题遵循项目已确认的受众和叙事口径；未定口径时可用完整主张句。页体用图像、场景、空间关系或已核对数字作证据，避免把同一句拆成四条 bullet；不要求每页有数字。

## 拨杆（室内概念册建议）
- DENSITY **3–4**（一页一意；留阅册可略密，但勿 cockpit）
- MOTION **2–3**（少动画；概念册以静态接触片为准）
- VARIANCE **5–6**（禁连续三页同版式；与审美基线一致）

## 页型轮换（从中取 5–8，轮着用）
Cover · 章节扉 · 主张-证据 · 大数字/指标 · 平面/动线 · 材料/色板 · 对比（现状/方案）· 收束带边界  
禁：每页「标题+四条 bullet」同一模具；空 Agenda；空「谢谢/Q&A」壳页。

## 室内硬禁（AI 脸）
- 默认蓝金海军、标题底线、贯穿色条（与审美基线一致）
- 三件套相同卡片凑「三大亮点」
- emoji 作项目符号；SmartArt 风装饰
- 空壳「设计理念」页无主张无证据
- 效果图上浮不可读小字（无遮罩）

## Signature（强制声明一个）
须同时：可记住、来自本项目内容、全册贯穿。例：「潮汐时段轴贯穿公区」「一条铝条母题串起接待到会议」。不能写清一句 = 没有。

## Pre-flight（任一未豁免失败 = 不放行）
- [ ] 只读标题能沿项目已确认的视角讲完故事（titles-only）
- [ ] 无 bullet 墙作主内容；一页一主张
- [ ] 无空壳页
- [ ] Signature 有且仅一个、贯穿
- [ ] 未连续三页同版式
- [ ] 锁模几何/母题 chrome 未被本 skill 改动
- [ ] 收束页有边界或下一步，不是空「谢谢」
